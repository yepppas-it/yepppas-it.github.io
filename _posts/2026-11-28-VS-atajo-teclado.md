Visual Studio Code (VSCode) es un editor de código fuente gratuito, ligero y multiplataforma desarrollado por Microsoft que funciona en Windows, macOS y Linux. 

A diferencia del Visual Studio completo, se enfoca en ofrecer un entorno rápido y personalizable para editar, depurar y gestionar proyectos de software en prácticamente cualquier lenguaje de programación 

Una de las características más interesantes de VSCode es la gran cantidad de [atajos de teclado](https://code.visualstudio.com/docs/reference/default-keybindings) que incorpora. En este artículo, voy a listar algunas de las que considero más útiles.

## Atajos de teclado
